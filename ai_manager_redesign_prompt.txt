# Existing Project Prompt – Tolee AI Manager (User Experience Flow)

## Objective

Completely redesign the **Tolee AI Manager** into a modern **ChatGPT-style AI Workspace** where users can naturally interact with AI to manage their entire Tolee experience. The AI Manager should no longer feel like a traditional dashboard—it should function as an intelligent personal assistant that understands the user's needs and helps them perform tasks through conversation.

**Important:** This redesign is for the **user experience when they open the AI Manager from the left-side navigation menu**. All existing AI features and business logic must continue working without interruption.

---

# User Journey

## Step 1 – User Clicks "AI Manager"

When the user clicks **AI Manager** from the left sidebar:

- Open a dedicated AI Workspace page.
- Do **NOT** show the current dashboard layout.
- Replace it with a clean, ChatGPT-inspired interface.
- The page should load instantly with a lightweight, modern UI.

---

# Step 2 – AI Workspace Layout

### Left Sidebar (Collapsible)

Move the existing AI modules into a collapsible sidebar similar to ChatGPT.

Include:

- ➕ New Chat
- 🕘 Recent Chats
- 📁 Saved AI Projects
- 📚 Prompt Library
- 🧠 AI Templates
- 📜 AI History
- ⭐ Favourite Chats
- 📦 Archived Chats
- ⚙ Settings

### Sidebar Behaviour

Desktop:
- Collapse / Expand

Mobile:
- Swipe Left → Hide
- Swipe Right → Show

The behaviour should feel exactly like ChatGPT.

# Expected Result

When a user clicks **AI Manager** from the left navigation menu, they should feel like they have opened a professional AI assistant similar to ChatGPT. The interface should immediately explain everything the AI can do, guide the user with helpful suggestions, and allow them to manage posts, ads, news, comments, chats, reminders, meetings, calendars, and business growth through a single intelligent conversational workspace. The experience must be modern, responsive, lightweight, and fully compatible with all existing Tolee functionality without introducing regressions.
