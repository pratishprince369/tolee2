## 🛡️ Global Security Standards
Every mutation action exposed below automatically undergoes:
1. **Authentication Verification**: NextAuth session validation using \`getServerSession(authOptions)\`.
2. **Double XSS Sanitization**: Input cleaning via \`sanitizeText\` / \`sanitizeHTML\` filters.
3. **Database Security**: Automated query parameterization by Prisma to block SQL injections.
4. **Traffic Rate Limiting**: Multi-bucket IP throttling via central rate limit middleware.
